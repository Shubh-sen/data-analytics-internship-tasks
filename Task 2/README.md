# Customer Segmentation Analysis - Task 2

## Project Overview

This project performs customer segmentation on the **UCI Online Retail** dataset using **RFM (Recency, Frequency, Monetary) analysis** and **K-Means clustering**.

The objective is to identify distinct customer groups based on purchasing behaviour and recommend targeted marketing strategies for each segment.

## Objective

- Calculate customer-level RFM metrics
- Analyse average purchase value, purchase frequency, and historical customer value
- Standardise behavioural features using `StandardScaler`
- Determine the optimal number of clusters using the Elbow Method
- Apply K-Means clustering
- Visualise customer segments
- Profile each cluster
- Recommend marketing actions for each customer segment

## Dataset

**Dataset:** UCI Online Retail

The dataset contains transaction-level information such as:

- Invoice Number
- Product Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

The analysis excludes cancelled transactions, missing Customer IDs, invalid dates, and non-positive quantity/price records.

## RFM Analysis

### Recency
Number of days since the customer's most recent purchase.

### Frequency
Number of unique invoices associated with the customer.

### Monetary
Total historical revenue generated by the customer.

### Customer Lifetime Value

For this project, historical **Monetary value is used as an observed CLV proxy**. It represents the customer's accumulated historical spend in the available dataset and is not a prediction of future lifetime value.

## Clustering Features

The following behavioural features are used for K-Means clustering:

- Recency
- Frequency
- Monetary

Before clustering, the features are standardised using `StandardScaler`.

## Clustering Method

**Algorithm:** K-Means Clustering

**Optimal K:** 4

The Elbow Method is used to identify a practical number of clusters. A silhouette score is also calculated as an additional cluster-quality diagnostic.

## Customer Segments

### Champions / VIP

Highly recent customers with exceptionally high purchase frequency and historical spending.

**Recommended actions:**
- VIP loyalty programme
- Exclusive offers
- Early access to new products
- Personalised recommendations
- Retention campaigns

### Loyal High-Value

Recent repeat customers with strong purchase frequency and monetary value.

**Recommended actions:**
- Loyalty rewards
- Cross-selling
- Personalised promotions
- Early-access campaigns

### Regular Customers

The largest customer segment with moderate purchasing activity and spending.

**Recommended actions:**
- Upselling
- Cross-selling
- Product bundles
- Loyalty incentives
- Frequency-building campaigns

### At-Risk / Low-Value

Customers with relatively high recency and lower purchase frequency and spending.

**Recommended actions:**
- Win-back campaigns
- Personalised reminders
- Limited-time reactivation offers
- Targeted incentives

## Key Insights

1. A small group of VIP customers contributes disproportionately high historical customer value.
2. Regular Customers form the largest segment and represent a major opportunity for increasing purchase frequency and order value.
3. At-Risk customers should be targeted with reactivation campaigns.
4. High-frequency customers generally contribute significantly higher historical monetary value.
5. RFM segmentation allows marketing resources to be allocated according to customer behaviour.
